# PitchLab 0.2 — Vocal tuning study

Windows 10/11 x64용 실시간 보컬 음정 보정 앱입니다. 원형 음정 표시, 다이얼, 음 선택 건반을 중심으로 화면을 다시 구성했습니다. 마이크 녹음과 기존 WAV 파일 보정을 지원합니다. 오디오는 서버로 전송하지 않습니다.

[실행 파일과 전체 소스](https://github.com/YSL-RyuDo/pitchlab/releases/tag/v0.2.0)

![PitchLab 0.2](PREVIEW.png)

## 사용하기

ZIP을 풀고 `PitchLab.exe`를 실행하세요. 시작할 때 오디오 장치를 자동으로 열거나 소리를 재생하지 않습니다.

**기존 목소리 파일:** 프리셋과 키·스케일을 선택하고 **WAV 파일 보정**을 누릅니다. 녹음 폴더에 `_tuned.wav`, `_original.wav`, `_report.txt`가 생깁니다. 자동 재생하지 않습니다. 처리 시작 시 설정을 사용하며, 처리 도중 변경은 다음 파일에 적용됩니다. 16–96 kHz, 모노/스테레오, 최대 1시간 WAV를 지원합니다. 스테레오는 모노로 평균합니다. 파일 처리 시 지연을 제거하므로 원본과 결과 길이가 같습니다. 음량을 자동 정규화하지 않습니다.

**마이크:** **오디오 설정 → 마이크 시작 → 녹음 시작** 순서입니다. 보정음과 원본을 별도 24-bit 모노 WAV로 저장합니다. **헤드폰으로 듣기**를 켜야 출력됩니다. 듣기를 꺼도 녹음됩니다. Windows와 헤드폰 자체 음량을 낮게 두고 시작하세요. 기존 0.1.0은 사용하지 마세요.

**강하게 음에 붙는 효과:** `Hard tune`을 선택하고 노래의 키·스케일을 맞추세요. 건반으로 보정에 사용할 음을 직접 고를 수 있습니다. 건반은 소리를 내는 악기가 아닌 음 선택기입니다. 모든 음을 끌 수는 없습니다.

## 조절

| 조절 | 동작 |
|---|---|
| Retune speed | 작을수록 목표 음에 빨리 붙습니다. 전체 오디오 지연과 다릅니다. |
| Correction | 음정 이동량. 100%는 목표 음까지, 0%는 이동 없음. |
| Humanize | 같은 음을 길게 유지할 때 보정을 느리게 하여 작은 흔들림을 남깁니다. |
| Headphones | 듣기 음량만 변경하며 녹음 음량과 독립적입니다. |
| Voice range | 자동 65–1000 Hz / 낮은 음역 65–400 Hz / 높은 음역 130–1000 Hz |
| 목소리 음색 유지 | Rubber Band의 포먼트 보존 기능 |
| 보정 켜기 | 끄면 지연을 맞춘 원래 소리로 전환. 출력 보호는 유지. |
| Key / Scale / 건반 | Chromatic, Major, Minor, Minor pentatonic, 직접 선택한 음 |

| 프리셋 | Retune | Correction | Humanize |
|---|---:|---:|---:|
| Natural vocal | 45 ms | 85% | 65% |
| Tight pop | 5 ms | 100% | 15% |
| Hard tune | 0 ms | 100% | 0% |

다이얼을 직접 바꾸면 `Custom`으로 표시합니다. 프리셋은 헤드폰 음량을 높이거나 듣기를 켜지 않습니다. 설정은 앱을 닫으면 초기화됩니다.

## 처리 변경과 진단

짧은 자음·무성음 구간에서는 기존 보정 비율을 유지하고 긴 무음에서는 부드럽게 복귀합니다. 긴 음의 Humanize, 음역 선택, 직접 고른 음으로 보정하는 기능을 추가했습니다. 직접 고른 음으로 최대 한 옥타브 이내에서 이동하며, 큰 이동은 음색 변화가 생길 수 있습니다.

무거운 피치 처리는 별도 스레드에서 수행합니다. **진단 저장**은 장치 이름, 처리 시간, 시간 초과 블록, 입력/출력 버퍼 이상, XRUN을 녹음 폴더에 기록합니다. 음성 내용은 포함하지 않습니다. 오류로 멈추면 자동 저장합니다. 시작 0.5초 이후 드라이버 XRUN 증가도 화면 타이머에서 감지해 출력을 끄고 녹음을 중단합니다. 드라이버가 보고하지 않는 끊김은 이 수치로 검출할 수 없습니다.

오류: 1 입력 버퍼 넘침, 2 출력 데이터 부족, 3 비정상 신호, 4 DSP 스레드 시작 실패, 5 드라이버가 보고한 끊김. 오류 이후 듣기를 자동 재개하지 않습니다.

## 출력 보호와 한계

헤드폰 기본 게인은 -36 dB, 범위는 -60~-18 dB이며 켤 때 250 ms에 걸쳐 올라갑니다. 보정 파일은 고정 -6 dB 게인과 최대 0.5의 미리보기 제한기를 거칩니다. 헤드폰 경로는 최대 0.03(약 -30.5 dBFS)까지 별도로 제한합니다. 디지털 제한은 실제 헤드폰 음압을 보장하지 않습니다.

48 kHz / 장치 버퍼 512 기준 지연은 약 **107 ms + 장치 지연**입니다. DELAY는 계산값과 드라이버 보고치이며 물리적 왕복 측정값이 아닙니다. 상용 플러그인 수준의 낮은 지연을 달성했다고 주장하지 않습니다.

한 사람의 분리된 보컬용입니다. 반주, 숨소리, 거친 발성, 여러 사람 입력은 검출 오류가 생길 수 있습니다. 기존 헤드폰 지직거림의 원인은 실제 장치에서 재현하지 못했습니다. 합성 신호와 공개된 실제 **발화** 파일로 처리 동작을 검사했으며, 실제 노래의 자연스러움·마이크/헤드폰 끊김 해소·상용 Auto-Tune과 동등한 품질은 검증하지 않았습니다.

가상 마이크, VST, ASIO는 포함하지 않습니다. 윈도우 녹화·디스코드의 마이크를 자동 교체하지 않습니다. 앱 자체 WAV 녹음 기능을 사용하세요. 상용 제품의 코드·브랜드·화면 자산은 사용하지 않았습니다.

## 빌드와 검사

Visual Studio 2022 C++ 데스크톱 개발 도구, Windows SDK, CMake 3.24 이상이 필요합니다. `build.ps1`은 포함된 의존 소스 아카이브 또는 고정된 Git 커밋을 사용해 빌드하고 내장 검사를 실행합니다.

CLI는 `--self-test 출력폴더`, `--render 입력.wav 출력폴더 프리셋번호`, `--render-ui 출력.png`를 지원합니다. 프리셋 번호는 0 Natural / 1 Tight / 2 Hard입니다. 경로에 공백이 있으면 따옴표로 감싸세요. 세 모드 모두 오디오 장치나 재생을 사용하지 않습니다. UI 렌더는 창 없이 컴포넌트를 이미지로 그립니다.

`TEST-RESULTS.txt`는 내장 검사, `VOICE-TEST-RESULTS.txt`는 외부 WAV 재읽기 검사 기록입니다. 합성음의 기본 음정 외에 직접 음 선택, 비브라토 보정 반응, 출력 제한, 버퍼 이상, 비정상 수치, 프리셋과 건반의 DSP 전달을 검사합니다. WAV 검사는 실제 발화 약 45.5초를 Natural/Hard로 각각 처리한 6회와 짧은 스테레오·무음 각 2회입니다. 길이·원본 정렬·무음·출력 상한·프리셋 차이를 확인했고 소리는 재생하지 않았습니다.

외부 검증: `python Tests/verify_render.py INPUT OUTPUT`. Python 표준 라이브러리만 사용합니다. 입력은 24-bit PCM WAV, 결과 폴더는 `OUTPUT/preset-0/입력이름/` 및 `OUTPUT/preset-2/입력이름/` 구조입니다.

발화 출처: [librosa 예제](https://librosa.org/doc/dev/recordings.html), [LibriSpeech SLR12](https://www.openslr.org/12/), CC BY 4.0. Garth Comira(5703-47212-0000), Heather Barnett(198-209-0000), Anders Lankford(3436-172162-0000). 테스트에서는 librosa/data의 22050 Hz OGG를 48000 Hz PCM으로 변환했습니다. 발화 파일과 그 처리 결과는 배포하지 않습니다. `Examples`는 프로젝트에서 생성한 합성 테스트 음입니다.

## 소스

- `PitchEngine.h`: YIN, 음역/음 선택, Humanize, Rubber Band 피치 이동
- `AudioEngine.h`: 장치, DSP 스레드, FIFO, 시간 계측
- `OutputGuard.h`: 미리보기 제한기, 헤드폰 페이드/차단
- `OfflineRenderer.h`: WAV 처리, 지연 제거, 결과 기록
- `Recorder.h`: 원본/보정음 WAV 쓰기
- `VocalKeyboard.h`, `Main.cpp`: 건반, 다이얼, 파일 처리, 진단

JUCE 8.0.15, Rubber Band 4.0.0을 사용합니다. 프로젝트 소스는 AGPL-3.0-or-later이며 `LICENSE.txt`와 `ThirdParty` 라이선스를 확인하세요. 의존 라이브러리 전체 소스 아카이브는 릴리스 ZIP에 포함합니다.
