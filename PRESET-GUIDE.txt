PitchLab 0.4.1 — 보컬 스타일 가이드

이름은 참고한 음악적 방향을 뜻합니다. 공식 프리셋, 실제 세션 파일,
아티스트의 승인 또는 목소리 복제를 의미하지 않습니다. 아래 숫자는
PitchLab용으로 직접 설계한 값이며 Auto-Tune에 그대로 대입하는 값이 아닙니다.
특정 곡의 분리 보컬을 청취·측정하여 역산한 결과도 아닙니다.

프리셋                  Retune  Correction  Humanize  Echo       설계 방향
T-Pain / Snap              0ms     100%        0%     8분음표    즉시 붙는 음정, 작은 공간
Travis Scott / Space       3ms     100%        8%     4분음표    어두운 톤, 포화, 긴 메아리

사용 순서
1. 프리셋을 고르고 곡의 KEY / SCALE을 맞춥니다. 건반으로 음을 직접 고를 수도 있습니다.
2. 마이크 시작 전에 SONG BPM을 곡에 맞춥니다. 기본값 140은 어떤 래퍼의 고정 BPM이 아닙니다.
3. STYLE FX 100%가 설계한 효과 양입니다. 잔향이 많으면 줄이세요.
   0%에서는 음색/메아리/룸을 빼고 해당 프리셋의 음정 보정만 남깁니다.
4. 녹음 크기는 +18 dB에서 시작하고 여전히 작으면 +24 dB를 시도합니다.
   이미 큰 입력은 0 dB에 가깝게 낮추세요. 큰 증폭은 잡음도 키우며 제한기에
   계속 닿으면 질감이 거칠어질 수 있습니다. HEADPHONES는 저장 음량과 별개입니다.
5. 녹음 끝부분의 잔향을 남기려면 노래가 끝난 뒤 1~2초 기다렸다 녹음을 끝내세요.

프리셋을 바꿔도 KEY/SCALE/직접 선택한 음, BPM, 헤드폰 음량, 녹음 크기는 유지합니다.
잡음 차단 설정도 유지합니다. 기본 -60 dBFS이며 대기 잡음이 남으면 -54,
작은 목소리가 잘리면 -66 쪽으로 조절합니다. 실제 장치 끊김을 복구하지는 않습니다.
기본 Natural vocal / Tight pop / Hard tune에는 스타일 효과가 없습니다.
음정 다이얼이나 STYLE FX를 직접 바꾸면 Custom으로 표시합니다.
현재 설정은 앱을 종료하면 초기화됩니다.

조사 근거와 직접 설계한 부분

Antares의 설명은 T-Pain식 효과의 핵심으로 거의 0에 가까운 Retune Speed를
들고, Travis Scott 등의 음악에서 음정 보정이 적극적인 음색 표현으로 쓰임을
설명합니다. 이 자료에서 Snap의 빠른 보정 방향을 참고했습니다.
https://www.antarestech.com/blog/auto-tune-impact-on-hip-hop-industry
https://help.antarestech.com/hc/en-us/articles/41076455881364-How-can-I-get-that-classic-Auto-Tune-effect

Future의 엔지니어 Seth Firkins는 Sound On Sound 인터뷰에서 녹음 중
Auto-Tune, 4분음표 딜레이, 룸 리버브를 듣는 방식을 설명했습니다.
해당 세션의 리버브는 12~15% 믹스와 12ms 프리딜레이였습니다.
Future / Room은 이 구성 방향을 참고했지만 D-Verb나 그 세션을 재현하지는
않습니다. PitchLab의 룸 합산 계수 0.13은 D-Verb의 13% 믹스와 동등하지 않습니다.
https://www.soundonsound.com/techniques/inside-track-future-draco

Travis의 3ms, Future의 7ms 및 각 음색/압축/공간 계수는 자체 설계값입니다.
식케이·창모·ASH ISLAND의 정확한 플러그인 체인이나 Retune 수치를 확인할 수
있는 1차 자료는 확보하지 못했습니다. 국내 세 가지는 밝은 훅/전면 싱잉랩/
긴 잔향이라는 서로 다른 연습용 방향으로 만든 근사 프리셋입니다.

추가한 NOWIMYOUNG와 Royal 44도 정확한 세션 설정은 확인하지 못했습니다.
확인한 당사자 인터뷰는 음악 활동과 표현 방향을 다루며, 플러그인 수치를
제공하지 않습니다. Bright의 4ms/고음 강조, Melodic의 16ms/긴 잔향은
이 프로젝트의 설계 선택이지 인터뷰에 나온 설정값이 아닙니다.
https://www.esquirekorea.co.kr/article/1906014
https://www.elle.co.kr/article/1898225

구현과 한계
스타일은 저음 정리 → 고음 조절 → 3:1 압축 → 부드러운 포화 → 박자 딜레이와
간단한 룸 처리를 사용합니다. 실시간 처리를 위해 버퍼를 미리 할당하며
스타일 전환은 약 20ms로 부드럽게 섞습니다. 스테레오 확장, 더블링 레이어,
성별/성대 변환 또는 아티스트 음성 모델은 포함하지 않습니다.
파일은 24-bit 모노입니다. 스테레오 입력도 두 채널을 평균해 모노로 처리합니다.
파일 보정은 길이를 유지하므로 입력 파일 끝 이후의 효과 꼬리는 덧붙이지 않습니다.
실시간 경로는 Signalsmith, WAV 보정은 Rubber Band라 질감이 다를 수 있습니다.
실제 청취 및 아티스트와의 유사도는 검증하지 않았습니다.

작게 녹음된 기존 WAV
마이크를 멈추고 녹음 크기를 정한 뒤 '기존 WAV 음량 키우기'를 누릅니다.
별도 _louder.wav를 만들며 음정 보정이나 스타일 효과를 다시 적용하지 않습니다.
입력 파일을 덮어쓰지 않습니다. 증폭만으로 기존 잡음이나 깨진 파형을 복구할 수는 없습니다.
최종 파일 상한은 -1 dBFS 샘플 피크입니다. LUFS/트루피크 정규화 기능은 아닙니다.
